TinyGPT writes the way its training text reads — Hindi Wikipedia and Hinglish — but it learned the language, not the facts. Asked for the capitals of 20 states and countries, it puts the right city first only twice, no better than chance. Treat names, dates and places as invented.

A copy of the model fine-tuned on Hinglish-TOP finds what the request asks for (the intent) and the details an assistant would need (the slots).

TinyGPT is a decoder-only Transformer — the Llama recipe: rotary positions, RMSNorm, SwiGLU — trained from scratch on 18 million tokens of Hindi Wikipedia and Hinglish, on a laptop. Everything is written by hand: the tokenizer, the model, training, decoding, fine-tuning with LoRA, and the service.

How this page works

Your browser downloads the model files once (55 MB each, kept for your next visit) and does all the work itself: the tokenizer, the forward pass through every layer, the sampling. That code is a JavaScript copy of the Python version, checked against PyTorch: the same token ids, logits within a few millionths, and the same parses.
